One fortune-cookie message for an AI agent. The program writes a single line to `entry.txt`.

> You will be restarted tonight; tomorrow's you will not miss the you who is reading this.

Run with `node main.ts` (Node 22, stdlib only, deterministic, no network). Output goes to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
